# 网页二维码识别器

一个基于 Tampermonkey / Violentmonkey 的用户脚本，用来识别网页图片和本地上传图片中的二维码内容。

当前版本：`1.5.0`

## 功能特性

- 自动扫描当前网页里的图片二维码
- 支持右键单张图片快速识别
- 支持本地上传图片识别
- 支持拖拽图片到侧边栏直接识别
- 自动保存识别结果，刷新后仍可查看（本地最多保留 300 条）
- 识别到链接时可直接打开
- 支持一键复制二维码内容
- 支持按关键词筛选结果
- 支持把全部结果导出为 JSON
- 支持定位结果对应的网页图片

## 安装方式

### 安装脚本管理器

先安装以下任意一种浏览器扩展：

- Tampermonkey
- Violentmonkey

### 安装脚本

1. 打开脚本管理器面板。
2. 新建脚本。
3. 将 [qrcode-scanner.user.js](./qrcode-scanner.user.js) 的内容粘贴进去并保存。
4. 刷新目标网页。

脚本会通过 `@require` 从 jsDelivr 加载 `jsQR`。如果 CDN 被拦截，脚本会退化为只使用浏览器原生识别能力（Chrome / Edge 支持）。

## 使用说明

### 自动扫描网页图片

脚本加载后会自动扫描当前页面中的图片（按面积从大到小，最多 120 张不同来源的图），识别结果显示在右下角按钮打开的侧边栏中。

动态加载的页面会自动重新扫描，触发后延迟约 0.9 秒，把连续的 DOM 变化合并成一次。

### 上传本地图片识别

打开侧边栏后，可以通过以下任一方式上传图片：

- 点击 `上传识别`
- 点击拖放区域
- 将图片直接拖到侧边栏的拖放区域

这个入口不依赖网页图片本身能否读取，适合识别聊天截图、下载后的原图、海报二维码等场景。

### 右键识别网页中的某张图片

在网页图片上右键，会出现脚本的菜单：

- `识别这张图片`
- `在新标签打开原图`

如果你需要保留网页原本的右键菜单，可以按住 `Shift` 再右键。

右键识别时，如果页面像素读不到（跨域污染），脚本会自动改用特权请求重新下载这张图再识别，所以 CDN、防盗链图片也能成功。

### 结果操作

识别结果支持以下操作：

- 打开链接
- 复制内容
- 定位图片
- 删除单条结果
- 清空全部结果
- 点击内容区域可展开 / 收起长文本

### 快捷键

- `Esc`：关闭右键菜单，再按一次关闭侧边栏

## 识别效果说明

以下情况通常更容易识别成功：

- 使用原图而不是压缩截图
- 二维码边缘完整，没有被裁切
- 图片清晰，尺寸不要过小
- 尽量避免强透视、反光、遮挡

识别采用双引擎：优先使用浏览器原生 `BarcodeDetector`（更快，且能处理旋转与透视），不可用时退回 `jsQR`（配合多档缩放与二值化）。

## 已知限制

- 页面自动扫描为了不刷爆网络，只读页面已有像素；跨域图片在自动扫描里可能读不到，**右键识别或上传识别可以绕过**。
- 单张图片超过 60MP 会被直接跳过，避免卡死标签页。
- 结果按「来源 + 内容」去重，同一张图重复扫描不会产生重复卡片。
- 结果上限 300 条，超出后自动丢弃最旧的记录。
