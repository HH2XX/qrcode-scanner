# 网页二维码识别器

一个基于 Tampermonkey / Violentmonkey 的用户脚本，用来识别网页图片和本地上传图片中的二维码内容。

当前版本：`1.4.0`

## 功能特性

- 自动扫描当前网页里的图片二维码
- 支持右键单张图片快速识别
- 支持本地上传图片识别
- 支持拖拽图片到侧边栏直接识别
- 自动保存识别结果，刷新后仍可查看
- 识别到链接时可直接打开
- 支持一键复制二维码内容
- 支持定位结果对应的网页图片

## 安装方式

### 安装脚本管理器

先安装以下任意一种浏览器扩展：

- Tampermonkey
- Violentmonkey

### 安装脚本

1. 打开脚本管理器面板。
2. 新建脚本。
3. 将 [qrcode-scanner.user.js](./qrcode-scanner.user.js) 的内容粘贴进去并保存。
4. 刷新目标网页。

## 使用说明

### 自动扫描网页图片

脚本加载后会自动扫描当前页面中的图片，识别结果会显示在右下角按钮打开的侧边栏中。

### 上传本地图片识别

打开侧边栏后，可以通过以下任一方式上传图片：

- 点击 `上传识别`
- 将图片直接拖到侧边栏上传区域

这个入口不依赖网页图片本身是否能正常读取，适合识别聊天截图、下载后的原图、海报二维码等场景。

### 右键识别网页中的某张图片

在网页图片上右键，会出现脚本的菜单：

- `识别这张图片`
- `在新标签打开原图`

如果你需要保留网页原本的右键菜单，可以按住 `Shift` 再右键。

### 结果操作

识别结果支持以下操作：

- 打开链接
- 复制内容
- 定位图片
- 删除单条结果
- 清空全部结果

## 识别效果说明

以下情况通常更容易识别成功：

- 使用原图而不是压缩截图
- 二维码边缘完整，没有被裁切
- 图片清晰，尺寸不要过小
- 尽量避免强透视、反光、遮挡

## 已知限制

- 某些网站会对跨域图片做限制，导致网页内直接识别失败。
- 如果右键识别失败，优先建议打开原图或下载后走“上传识别”。
- 动态加载页面会自动重新扫描，但极端复杂页面可能需要手动点一次 `重新扫描`。
