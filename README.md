# 网页二维码识别器

**版本**: 1.0.1  
**描述**: 浏览器扩展/油猴脚本，自动识别网页二维码，右键图片扫描，结果永久保存。

## 功能

- ✅ 自动扫描页面二维码  
- ✅ 右键图片 → “识别此二维码”  
- ✅ 结果持久保存（关闭后仍可查看）  
- ✅ 一键复制/打开链接  
- ✅ 定位图片在页面位置  

## 安装

### Chrome/Edge

1. 打开 `chrome://extensions/`  
2. 开启“开发者模式”  
3. “加载已解压的扩展程序”，选择项目根目录  

### 油猴

1. 安装 Tampermonkey/Violentmonkey  
2. 下载 `qrcode-scanner.user.js`  
3. 在管理器中新建脚本粘贴代码  

## 使用

- 点击浏览器右上角图标打开侧边栏  
- 右键任意图片 → “识别此二维码”  
- 结果弹窗可复制、打开、定位  

## 说明

结果会自动保存在本地，关闭后下次打开仍可见。如有跨域图片提示，建议双击原图后再识别。
